◆ XOR / XNOR Feedback & Lockup State Prevention

The linear feedback function determines which binary state becomes a self-looping forbidden (lockup) state, and why a maximal-length n-bit LFSR cycles through exactly 2n − 1 non-repeating states.

  • Why XOR locks at 0000: If all tapped flip-flops are 0, 0 ⊕ 0 = 0. Every rising edge shifts another 0 into Qn-1, trapping the register indefinitely.
  • How XNOR prevents all-zero lockup: Since XNOR(0, 0) = 1, a power-on reset to 0000 automatically injects a 1 (0000 → 1000) and enters the 15-state cycle. (Instead, 1111 becomes the lockup state for even-tap polynomials.)
  • Hardware Recovery Guard: Practical ASIC/FPGA designs add either asynchronous PRESET on one D-FF during reset or a multi-input NOR detector across Qn-1..Q₀ OR-ed into the feedback path to guarantee zero-state recovery.
Primitive Polynomial Rule: Only polynomials primitive over Galois Field GF(2) (such as x⁴ + x³ + 1 or x⁴ + x + 1) achieve the full period 2n − 1 = 15. Non-primitive polynomials like x⁴ + x² + 1 partition states into shorter sub-cycles.
03 Real-World Embedded & VLSI Applications
Hardware PRNGs
Cryptography & Security

Stream Ciphers & Keystream Generators

LFSRs form the core building blocks of hardware stream ciphers (e.g., GSM A5/1, Grain, and Trivium) because they require minimal silicon area and run at multi-GHz clock speeds.

Engineering Note: Because a single LFSR is linear over GF(2) (vulnerable to the Berlekamp-Massey algorithm after 2n bits), cryptosystems combine multiple irregularly clocked LFSRs with non-linear filter functions.

VLSI Testing

Built-In Self-Test (BIST)

In SoCs and FPGAs, an on-chip LFSR acts as a Pseudo-Random Test Pattern Generator (TPG) applying exhaustive or near-exhaustive vectors to combinational logic blocks without expensive external ATE testers.

A companion LFSR configured as a MISR (Multiple-Input Signature Register) compresses millions of test responses into a single deterministic golden signature.

RF, DSP & Comms

Noise Generation, Scramblers & CDMA

Maximal-length (m-sequence) LFSRs exhibit white-noise-like autocorrelation spikes, making them ideal for digital AWGN / dither noise, GPS & CDMA Gold codes, and CRC error checking.

High-speed links (PCIe, SATA, Ethernet) use self-synchronizing LFSR scramblers to eliminate long runs of 0s or 1s for reliable clock data recovery (CDR).
